# Changelog

## 1.0.0 - iOS build 6

- Added server-side Earth Engine timeline cache status and warming endpoint.
- Added Redis/Memorystore-compatible tile caching support for the web/API service.
- Updated web and mobile timeline controls to use monthly Dynamic World data dates.
- Kept cache readiness separate from selectable data availability.
- Added mobile persisted preferences for selected location, visible layers, and selected date.
- Defaulted mobile layers to Tree cover and Forest loss.
- Added mobile tile loading progress text.
- Updated iOS build number to `6` for the latest TestFlight upload.
